# Portfolio

Source for [rezautomo.com](https://rezautomo.com) — Reza Dwi Utomo's personal portfolio site, built with plain HTML, CSS, and JavaScript and hosted on GitHub Pages.

## Structure

- `index.html` — main portfolio page
- `services.html` / `services-soon.html` — freelance services pages
- `css/` — stylesheets (`portfolio.css`, `services.css`, `custom.css`)
- `js/` — scripts (typewriter effect, collapsible sections, Medium feed)
- `images/` — site images
- `libs/` — third-party assets (Font Awesome)
